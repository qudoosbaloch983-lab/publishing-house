# School Landscape Redesign: CAD & PDF set

| File | Content |
|---|---|
| `School_Landscape_Final.dxf` | Editable AutoCAD 2018 DXF. Original geometry, units (inches) and coordinates are kept, with 6 A1 layouts (L-01 to L-06). |
| `School_Landscape_Drawing_Set_L01-L06.pdf` | All sheets in one PDF |
| `L-01` … `L-06` PDFs | Master plan, level plan, planting plan, material plan, sections A/B, sections C/D/E + pool edge detail |

**To get a DWG:** open the DXF in AutoCAD, run `SAVEAS`, then choose *AutoCAD 2018 Drawing (*.dwg)*.

## Layers
- `E-*`: existing items, unchanged (building, site boundary, roads, parking, gate, court, play equipment, pergolas).
- `X-OLD-LANDSCAPE`: the previous landscape scheme, frozen and kept for reference.
- `L-*`: the new landscape. Layers cover lawn, water body, pathways, paving by material, trees, shrubs, groundcovers, grasses, seasonal, aquatic, planting zones and tags, seating, steps, ramps, spot levels, FFL/FGL, contours, dimensions, labels, drainage, section marks and sections.

## Levels
The original CAD has no survey levels or contours, so every level is a **proposed, provisional** strategy.
- Benchmark: BM ±0.00 = crown of the main road at the NE gate.
- Building FFL is +0.60 (provisional); confirm it with the architectural drawings.
- Verify all levels on site with a topographic survey.
